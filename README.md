# Посмотри в окно

Проектная работа Яндекс Практикума: вёрстка CSS для готового приложения «Посмотри в окно».

## О проекте

Приложение показывает видео из окон в разных городах. Можно искать видео по городу и времени суток, переключать ролики кликом по карточке и подгружать новые карточки кнопкой «Показать ещё».

## Что сделано

- лейаут страницы на флексах;
- видео и превью подогнаны через `object-fit`;
- кастомные чекбоксы на псевдоэлементах;
- состояния `:hover`, `:active`, `:focus-visible` у кнопок, полей формы и карточек;
- обрезка длинных текстов (`text-overflow`, `line-clamp`);
- позиционирование прелоадеров и блока с ошибкой.

## Технологии

- HTML5
- CSS3 (Flexbox)
- JavaScript (логика приложения дана в заготовке)
